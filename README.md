# Cognitive Hazard AI 

Proactive Supply Chain Risk Intelligence engine. 

## Features
- **Classic RAG Mode:** Query static historical records using FAISS vector search.
- **Agentic Mode:** Real-time web analysis using Groq Llama 3.3 and Tavily search to identify causal risks.

## Tech Stack
- Frontend: Streamlit
- LLM: Groq (Llama 3.3 70b)
- Orchestration: LangGraph
- Vector Database: FAISS
